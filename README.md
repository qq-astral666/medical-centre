# МедЦентр Плюс — Корпоративный многостраничный сайт клиники

Современный, адаптивный многостраничный сайт для многопрофильной семейной медицинской клиники. Проект разработан на чистом коде без использования тяжелых сторонних фреймворков и библиотек, что обеспечивает максимальную скорость загрузки (100/100 в Google PageSpeed Insights).

## 🚀 Демонстрация
Вы можете посмотреть живую версию сайта по ссылке: [ССЫЛКА_НА_GITHUB_PAGES] *(укажи ссылку, когда включишь GitHub Pages)*

## 🛠 Технологический стек
* **HTML5:** Семантическая и валидная верстка всех страниц.
* **CSS3:** Современная сетка (Flexbox, CSS Grid), кастомные CSS-переменные, плавные анимации и кастомизированные интерактивные таблицы.
* **Vanilla JavaScript:** Чистый JS для логики интерактивного FAQ-аккордеона без jQuery и лишних зависимостей.

## 📱 Особенности проекта
* **Полный мобильный адаптив:** Сайт идеально отображается на любых устройствах — от старых смартфонов до 4K-мониторов.
* **Многостраничная структура:** 
  * `index.html` — Главная страница с промо-баннером, преимуществами, кратким каталогом услуг, отзывами, интерактивным FAQ и формой онлайн-записи.
  * `services.html` — Официальный прайс-лист клиники с адаптивными интерактивными таблицами стоимости услуг и диагностики.
  * `doctors.html` — Каталог специалистов с карточками врачей, их квалификацией, стажем работы и кнопками быстрой записи.
* **Оптимизация:** Быстрый рендеринг, оптимизированные шрифты и структурированный чистый код с подробными комментариями разработчика.
